# Редактор схемы
Дароу. 

Карта была сделана для тех мест, где старая уже неактуальна, а новую не могут сделать. 

На самом деле ничего сложного. После скачивания ахива - надо открыть файл index.html. Далее подгружаем кату (советую использовать план асположения камер. Он обычно есть у руководителя ЛО.)

Далее подгружаем картинку и расставляем кнопки камер. Воде не сложно, и интефейс очень френдли, но в случае, если помощь нужна - пишите в Band @myasnikov.igor2.

После того, как закончили редактирровать - сохраняем конфиг и готовый вариант. Конфиг нужен для того, чтобы можно было продолжить редактирорвать.
